Google Site Verification File

This is a template verification file for Google Search Console.

Instructions:

  1. Go to Google Search Console (search.google.com/search-console)
  2. Add your property: https://onlyappletech.in
  3. Choose "HTML file upload" verification method
  4. Download the verification file Google provides (e.g., google1234567890abcdef.html)
  5. Upload that file to your website's root directory (same folder as index.html)
  6. Click "Verify" in Google Search Console

Note: You do NOT need to edit this template file. Google will provide you with a unique verification file that you'll upload directly.

Alternative Method: If you prefer, you can use the HTML meta tag method instead. See google_search_console_setup.md for details.
